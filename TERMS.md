# TERMS — словарь проекта (только наши слова)

Правило: в текстах, именах кода, строках вывода, именах файлов и ключах конфига
употребляются **только** термины этого файла. Внешние названия (репозитории, API,
конвар-ы, цитаты чужих README) пишутся дословно и только в `бэктиках` или кавычках.
Соответствие нашим терминам чужих слов и список запрещённого лежат **вне рабочей
копии** — в `../observer-notes/GLOSSARY.md`; исполнителю отдельной задачи этот файл не нужен,
ему хватает таблицы ниже. Настоящие имена среды хоста (бинарники, пути, convar-ы, версии,
источники) в рабочей копии тоже запрещены: они живут в `../observer-notes/HOST-ENV.json`,
а здесь и в коде — только ручки (раздел «Среда хоста» ниже, PRINCIPLES P14).

## Продукт и режимы

| Наш термин | Что значит | В коде |
|---|---|---|
| наблюдатель | программа, которая опрашивает хост и рисует поверх | `ovr`, `ovr_core`, `ovr_lib`, бинарник `ovr` |
| надстройка | нейтральное имя класса таких программ | — |

| оператор | человек за клавиатурой и тот агент, которым он управляет | `local_operator` |

| встроенный доступ | наш код находится внутри процесса хоста | вне объёма M0–M7 |

## Среда хоста (ручки вместо настоящих имён)

Настоящее имя хоста — не термин, а конфигурация: в рабочей копии его нет. Всё, что называет
хост по имени, заменяется ручкой и разрешается через `HOST-ENV.json` (переменная `OVR_HOST_ENV`).

| Наш термин | Что значит | Как выглядит |
|---|---|---|
| среда хоста | всё, что названо настоящим именем хоста: бинарники, пути, convar-ы, версии, внешние источники | — |
| ручка | короткое имя из `HOST-ENV.json`, которое пишется в текстах, в JSON-контракты и вместо литерала в коде | `host_bin`, `version_file`, `cv.range_display`, `src-C` |
| разрешающий слой | `HOST-ENV.json` + генерируемый `host_env.hpp` (`ARCHITECTURE.md` §9) | единственное место, где появляется настоящее имя |
| стоп-лист среды | значения из `HOST-ENV.json`, которые ищет `scripts/check_host_env.py` в файлах и в сообщениях коммитов | P14 |
| словарь семьи движка | имена модулей и переменные, которые хост не выдают (`client.dll`, `sv_cheats`, `r_farz`) | остаются дословными цитатами |

| Ручка | Что разрешается | Где нужна |
|---|---|---|
| `host_bin`, `host_bin_linux` | исполняемый файл хоста | CLI дампера (T011), поиск процесса (T006) |
| `version_file` | файл версии клиента | `ClientVersion` и `is_stale()` (T003, T023) |
| `patch_current` | номер патча хоста | `contracts/info.client-<build>.json` (T002) |
| `cv.camera_distance`, `cv.range_display`, `cv.particle_fow` | convar-ы, в имени которых есть имя хоста | белый список записи (T022) |
| `src-A` … `src-H` | внешние источники исследования | `RESEARCH.md:14` и ссылки на доказательства |
| `cache_root` | каталог кеша источников | `RESEARCH.md:14` |

Правило чтения задачи: понадобилась настоящая строка (имя процесса, convar-а, файла) — берём
ручку и `HOST-ENV.json`; угадывать имя по памяти запрещено (P10, P14).
