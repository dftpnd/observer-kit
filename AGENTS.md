# Правила рабочей копии

- Термины — только из `TERMS.md`. Свои старые названия и чужие слова обратно не возвращать.
- Настоящих имён среды хоста в этом дереве нет и добавлять их не нужно: нужна настоящая строка —
  берём ручку (`host_bin`, `version_file`, `cv.*`, `src-*`) и разрешаем через `OVR_HOST_ENV`
  либо `host_env.hpp` (P14, `ARCHITECTURE.md` §9).
- Если ты исполнитель блока из `TASKS.md`: каталог `../observer-notes/` (декодер и реестр имён)
  не читать, не копировать к себе и не упоминать в коде, тестах и логах. Значения приходят только
  через генератор. Нет файла и нет фикстуры — ответ «контракт неполон» (P10), а не угаданное имя.
- Спорные места решаются по `PRINCIPLES.md`: стабильность > масштабируемость > незаметность.
- Формулировка задачи — закон. Не хватает ключа конфига, поля дампера или сигнатуры — «контракт
  неполон», новых имён и чисел от себя не добавлять (P6, P10).
- `git init` / `git commit` / `git push` не делать: коммиты остаются за заказчиком (`TASKS.md:33`).
