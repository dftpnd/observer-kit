# Эталон пустого кадра

`synthetic-empty.json` описывает искусственный кадр с пустым буфером и
`complete == false`. Значение `client_version: 0` означает неизвестную версию.
Тест проверяет SHA-256 обоих файлов из `MANIFEST.sha256`, затем один раз вызывает
`parse_frame` и сверяет поля результата с JSON. Значению `null` соответствует
снятый бит достоверности.

После сборки запусти `ctest --test-dir build -R golden --output-on-failure`.
Состояние при ошибке выводится по полям. Для приёмки T009 остаются нужны
подтверждённые пары JSON и BIN для состояний menu и play сборки 6985.
